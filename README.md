# USB MP3 Manager (Android)

## Test
1. Put a few `.mp3` files under `/storage/emulated/0/CCDownload/`.
2. Install and run the app.
3. Grant the audio read permission when prompted.
4. Verify the list shows only CCDownload `.mp3` files.
5. Pull down to refresh and confirm the list updates.
6. If permission is denied, confirm the inline message "未授予读取音频权限" and tap "授予权限".
7. If no files exist, confirm the inline message "该目录下没有MP3文件".
