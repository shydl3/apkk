# USB MP3 Manager (Android)

## Test with OTG USB drive
1. Connect a USB drive via OTG, ensure it is mounted by the system file manager.
2. Put a few `.mp3` files under `/storage/emulated/0/CCDownload/`.
3. Install and run the app.
4. On first launch, select the USB drive root in the SAF picker.
5. Use "本机MP3管理" to move or delete local MP3 files.
